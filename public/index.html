How to use

  1. Pick a target from the chips, or type a name (resolved by CDS Sesame) or coordinates (decimal or sexagesimal) and press ENGAGE.
  2. The tool lists every SPHEREx exposure covering that spot, reads only the small patch you need straight from NASA's public SPHEREx archive on AWS, and lines them all up north-up.
  3. PASSES plays one frame per 6-month all-sky pass. A source that jumps between frames is moving. DIFF shows each pass minus the others — red is where something is now, blue where it was.
  4. Toggle detectors D1–D6 (0.75–5 µm) to stack them. Brown dwarfs glow brightest in D5–D6.
  5. Click a source to build its spectrum (102 SPHEREx bands sampled on the fly) and light curve.
  6. Gaia DR3 circles are moved to each frame's date using their proper motions; AllWISE squares show where things were around 2010.
  7. Share the exact view with LINK, or embed it with EMBED — e.g. ?ra=133.79&dec=-7.245&fov=360&det=56.

Keys: space play/pause · ← → step · 1–6 toggle detectors · M cycle mode.
